# Desktop Hero

A lightweight, interactive desktop companion app built with Electron.

**Created by Shreyasrajalakshmi**
Instagram: @shreyasrajalakshmi

## Features
- Interactive Desktop Companions (Deadpool, Spider-Man, Zoro, and more)
- Mandatory Profile Setup with DOB-based age verification
- Multilingual Dialogue Engine (9 languages)
- 18+ Adult Mode with non-repeating shuffle pools
- Interactive Gift-Wrapped Wish Card rotating every 24 hours
- Red & Black / Red & White Themes
- Launch on system startup (macOS & Windows): on by default, one switch in the dashboard

## Quick Start
```bash
npm install
npm start
```
